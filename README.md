# Ahnaf MNM - Portfolio

Personal portfolio website for **Mohomad Najeel Mohomad Ahnaf**, a Computer Engineering student and Software Engineering Intern at the Sri Lanka Ports Authority (SLPA).

## Contents

- `portfolio.html` - Single-page portfolio website
- `Logo.png` - Personal logo used in the browser tab and loading screen

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Hero, skills, projects, experience, education, certifications, and contact sections
- Animated loading screen using the portfolio logo
- Custom favicon using `Logo.png`
- Scroll reveal animations and animated skill progress bars
- Particle background and custom cursor on desktop
- Project cards linked to GitHub repositories

## Run Locally

No build tools or dependencies are required. Open `portfolio.html` directly in a browser, or serve the folder with any static web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/portfolio.html`.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Syne and DM Sans
